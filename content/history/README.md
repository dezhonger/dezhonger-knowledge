# 历史站内容规范

`articles/` 存放叙事 Markdown，`data/` 存放结构化 JSON，`geo/` 存放经核实且允许再发布的 GeoJSON。三类内容分开维护，通过稳定 ID 关联。首批样本的来源核对和分歧见 [source-audit.md](source-audit.md)。

所有记录使用 `schemaVersion: 1`。当前采用的历史断言值只保存在实体字段中；`Assertion.target` 以实体类型、ID 和 JSON Pointer 指向该字段，不复制采用值。`Assertion.alternatives` 可保存被否定或尚未裁定的其他候选值、状态和理由；`adoptedCandidateId: "adopted"` 明确指向实体字段。`Evidence.candidateId` 指明证据支持哪一种候选值，并关联到 `Source` 的具体位置。这样同一事实的采用值只有一个数据来源。

日期用天文学纪年，0 表示公元前 1 年；展示时转换为公元前／公元后。有效区间为起点包含、终点不包含。中国历史日期保留原始纪年和历法、推算公历、转换依据及精度；无法可靠换算时允许标准化日期为空，但不能用猜测值填充。

地图文件必须附原始来源、许可证、署名要求、修改及再发布权限、绘制方法和边界精度。缺少任何一项时不作为正式疆域发布。

HISTORY ATLAS 是此域名的唯一内容系统。历史专用生成器拥有根首页 `/` 与 `/explore/`，并针对以前构建留下的课程页面和资源执行定向清理。历史事实、文章、证据链和地图素材与课程内容无关，继续保留。
