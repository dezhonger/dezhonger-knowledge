## 核心规则

被动语态的核心形式是 `be + 过去分词`，时态、情态和完成意义落在 be 及其前面的助动词上。主动句的宾语成为被动句主语，原主语只在必要时用 by 引出。

## 结构与例句

| 形式 | 例句 |
| --- | --- |
| 一般现在时 | The samples are tested daily. |
| 一般过去时 | The bridge was built in 2010. |
| 进行时 | The road is being repaired. |
| 完成时 | The work has been completed. |
| 情态动词 | The rule must be followed. |

## 使用场景

科学、新闻和正式说明常关注过程或结果而非执行者，因此常用被动。施事显而易见、未知、不重要或刻意不提时，可省略 by 短语。

## 常见错误

**错误：** The problem has solved. → **正确：** The problem has been solved。

**错误：** The accident was happened yesterday. → happen 是不及物动词，不能构成被动，应写 The accident happened yesterday。

## 易混知识点

`get + 过去分词` 也可表示被动，语气较口语并常突出变化或意外：He got injured。过去分词作形容词则描述状态：The door is closed 可能表示门处于关闭状态。

## 总结

先确认动词能否带宾语，再按所需时态构造助动词链，最后判断施事是否值得说明。
