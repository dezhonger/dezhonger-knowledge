## 归一规则

- 已有词条保留固定考试阶段、原词典释义、英美音标和来源，只增加主题关联及对应语境释义；新增主题词不随意指定考试等级。
- 相同拼写只保留一条数据。cold 在医疗语境显示“感冒”，在天气语境显示“寒冷的”；sink 在厨房语境显示“水槽”，在卫浴语境显示“洗手池”；teacher 在职业和学校语境分别显示“教师”和“老师”。
- 原文音标仅在能对应到明确英文项时保存为 reference；已有英美音标优先保留，不互相复制来补齐缺项。
- 客厅、卧室和阳台词汇统一关联既有 `home`；厨房和洗手间分别关联 `kitchen`、`bathroom`，避免为了房间名称增加首页展示层级。

## 重复导入

```bash
npm run import:english:topics -- \
  /path/to/society.md \
  /path/to/nature.md \
  /path/to/people.md \
  /path/to/home.md
```

导入脚本会解析表格与加粗清单、合并现有词条、校验每个来源项的目标主题，并更新覆盖报告。相同输入重复执行不会增加重复词条或重复释义；`--dry-run` 可只输出预估结果。
