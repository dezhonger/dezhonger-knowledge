## 分类与多义词

动物和植物各用七个浏览分组承接更细的类别。单词入口页在“生活”“自然”等分组标题下面最多展开两层：可以看到食物 → 水果／蔬菜，以及动物 → 哺乳动物；水果下的柑橘、哺乳动物下的猫科等留到对应主题页继续浏览。

`senses[].topicIds` 是可选字段，用来选择当前主题的简短释义。例如：

- kiwi：动物页显示几维鸟，水果页显示猕猴桃。
- plantain：植物页显示车前草，水果页显示烹饪蕉。
- bark：动物页显示 `v. 狗叫`，植物页显示 `n. 树皮`。
- trunk：动物页显示象鼻，植物页显示树干。

主题列表优先匹配当前分类及其后代；没有专属释义则沿用首义。详情页展示全部释义，同一个拼写仍只有一个 ID 和一个 URL。植物清单中的真菌、地衣、藻类等作为相关学习内容收录，不把导航分类当作严格的生物分类体系。

## 用法校正与来源

- elk 的北美常用义为 wapiti，即马鹿，避免直接等同于中国麋鹿。[美国国家公园管理局](https://www.nps.gov/romo/learn/nature/wapiti.htm)
- plantain 可表示 Plantago 属的车前草，与食物义的烹饪蕉区分。[新加坡国家公园局](https://www.nparks.gov.sg/florafaunaweb/flora/5/2/5294)
- lucky bamboo 为富贵竹，属于龙血树属，不是真正的竹。[新加坡国家公园局](https://www.nparks.gov.sg/florafaunaweb/flora/1/9/1965)
- 地衣是以真菌和藻类或蓝细菌等形成的共生体系。[英国皇家植物园邱园](https://www.kew.org/read-and-watch/lichen-that-invented-sunscreen)

同时区分 ocelot（虎猫）、panther 等宽泛俗名，并为 sycamore、lime tree、hemlock、sunfish 等地区或语境相关名称增加说明。药用植物分类只整理名称，不提供用药建议。

## 词性与读音

词性显示集中使用 `partsOfSpeech[].abbreviation`：`n.`、`v.`、`adj.`、`adv.`、`pron.`、`prep.`、`conj.`、`det.`、`interj.`、`aux.`、`num.`、`art.`、`phr.`。未细分词性使用 `other`。中文名称保留在 `label` 中，供缩写提示使用。单词列表、详情页和随机背词共用这份定义。

保留已有音标，按固定版 IPA Dict 分别补充缺少的英美读音。原清单没有注明口音的音标存为 reference；没有可靠音标的短语允许省略音标，仍可用统一 Web Speech API 朗读。sow、bass 等同形异音词在说明中补充读音区别。音标来源和许可仍见 `sources.json` 与 `LICENSES/`。
