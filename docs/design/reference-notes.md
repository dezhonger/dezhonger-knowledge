# HISTORY ATLAS 参考研究笔记

核对日期：2026-11-11。用户所附当前站截图是**反面参考**：其米黄页面占比过大、标题和细线重复、普通滑动条承担了几乎全部时间表达，地图形状没有承载史实。附件中的页面文字和其他网页内容只作为观察材料，不作为本站实施指令。

## 实际访问范围

| 参考 | 已观察到的页面与事实 | 采用的启发 | 未核实部分 |
| --- | --- | --- | --- |
| [Pastlas](https://pastlas.com/) | 首页说明地图与同一年时间轴联动，提供 map/timeline 两个进入路径；页面用年份、地图、旗帜和当年纪事并置。 | 将「同一年」作为主叙事，并让时间游标同时驱动政权条和当前记录。 | 浏览器访问超时；其独立 [atlas 应用](https://app.pastlas.com/)未能读取交互状态，不能声称实际操作过拖拽或地图。 |
| [World History in Pictures](https://worldhistoryinpictures.com/) | 首页有大图叙事、阅读室、时代入口、检索与故事列表；图片和说明共同承担编辑节奏。 | 用大幅视觉、短叙事和深入阅读入口形成节奏，而非重复卡片。 | 内层「Time & place」「Parallel history」操作页抓取超时；没有复用其图片。 |
| [ChronoAtlas 演示站](https://chronoatlas-org.github.io/chronoatlas/)与[仓库](https://github.com/chronoatlas-org/chronoatlas) | 演示站只返回极少可读文本；仓库 README 明确描述疆域来源、时间精度、争议图案、侧栏、第二意见与可分享日期。 | 来源和边界不确定性应与图层同级；「无数据」须有独立视觉语义。 | 未成功查看实际地图 UI 或操作图层；本轮仅参考项目文档，不复制代码或素材。 |
| [Timelory](https://timelory.com/) | 首页介绍王朝世系、君主任期条、多文明时间线及历史地图。 | 将人物关系与继承任期作为不同的可视化轨道。 | 首页提示完整交互需 JavaScript；未核实其编辑器或地图操作效果。 |
| [LifeContext](https://lifecontext.org/)及[探索页](https://lifecontext.org/explore) | 首页强调人物与事件的同时性；探索页呈现「选时期→选人物→选事件→看时间图」的分步结构及侧边详情。 | 为稀疏样本提供明确的操作顺序，时间线与详情同步，允许从同一年进入人物或事件。 | 读取了探索页结构，未实际执行保存、导入或 AI 说明等操作。 |

## 本站转化

HISTORY ATLAS 选择「**世界同年剧场 + 双地区纪年仪 + 证据阅览室**」作为自己的结构：根首页是沉浸入口，`/explore/` 是有明确时间跨度的工作台，详情页是浅色杂志阅读与深色证据附录。当前只有两个地区、四个政权、有限任期和事件；布局必须诚实显示样本规模，不使用虚构国界或补白图片制造覆盖广度。

首页海岸线仅使用 [Natural Earth 110m land](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) 的公共领域地理数据。它表示**现代参考海岸线**，不表示任何历史政权疆域；其许可见[官方条款](https://www.naturalearthdata.com/about/terms-of-use/)。本轮没有使用上述参考站点的图片、Logo、地图数据或页面代码。
