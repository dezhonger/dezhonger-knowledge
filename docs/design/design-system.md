# HISTORY ATLAS 设计系统

版本：0.1；2026-11-11。此规范约束 `history.dezhonger.com` 的首页、探索区与历史详情页。此域名只提供 HISTORY ATLAS。

## 1. 产品视觉定位

**现代数字历史博物馆 + 地理底图 + 高级历史杂志 + 可核查的数据可视化。** 用户第一眼看到的是「公元 1000 年的并行世界」，随后能沿时间轴进入政权、人物、事件及证据。视觉服务时间、空间与证据，不用仿古纹样冒充史料。

本站有三种场景：

| 场景 | 构图 | 主动作 |
| --- | --- | --- |
| 根首页 `/` | 深色满幅海岸线、超大年份、左右不对称导览；随后切换明亮编辑版面。 | 进入某年探索、阅读精选事件。 |
| 时间探索 `/explore/` | 深色地图参考区和浅色双地区时间谱；政权条、事件针、年份游标共用一条尺度。 | 拖动或键盘选择年份，点击政权条或事件针。 |
| 详情页 | 暖白杂志纸面、窄阅读栏、侧面关系索引、深色证据簿。 | 阅读、转到关联项、核查来源与异说。 |

## 2. 色彩系统

颜色分角色使用，不让暖纸色铺满所有页面。实现中的 CSS 自定义属性以此表为单一规范。

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--night` | `#0B1920` | 导航、首页及证据簿最深背景 |
| `--ocean` | `#102A32` | 地图舞台和探索台 |
| `--forest` | `#1D4945` | 地理参考与强调区域 |
| `--land` | `#466D68` | 公共领域海岸线填充 |
| `--brass` | `#E0B76F` | 主要时间游标、关键入口 |
| `--copper` | `#A55336` | 中国轨道及强调数据；白字对比度约 5.4:1 |
| `--aqua` | `#78BEC2` | 欧洲与地中海轨道 |
| `--ivory` | `#F5F7F3` | 阅读页主背景 |
| `--paper` | `#FFFFFF` | 阅读内页与浮起的证据项 |
| `--ink` | `#16282D` | 浅色页面标题与正文主色 |
| `--muted` | `#526368` | 辅助正文、元信息 |
| `--rule` | `#D4E0DD` | 有语义的分组边界 |
| `--warning` | `#925A3A` | 有争议、低精度提示 |

轨道颜色表达地区而非可信度。可信度另用文字、图案、虚线表达；不可仅靠色相区分历史主张。

## 3. 字体系统

展示字：系统宋体链 `"Songti SC", "Noto Serif CJK SC", Georgia, serif`，仅用于首页大字、页标题、年份和少量章节题。正文与界面：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", sans-serif`。数据标签和英文小字可用 `Inter, Arial, sans-serif`。不依赖网络字体，也不把整页排成宋体。

## 4. 排版

首页主标题桌面 68–112px、手机 42–58px；栏目题 34–54px；详情标题 52–88px；正文桌面 17–19px，行高 1.8–2.0；说明和引用 13–15px。年份大字可用 tabular numerals。来源标题允许换行，URL 不以裸文本撑破容器。每页最多一个 `h1`，章节层级连续。

## 5. 宽度、网格与间距

大屏内容最大 1440px；阅读文字最大 68ch；内页左右留白 `clamp(20px, 5vw, 88px)`。桌面 12 列概念网格：地图 7–8 列、导览 4–5 列；详情正文 7 列、关系索引 3 列、中缝 2 列。间距级数 4/8/12/20/32/48/72/104px。留白用于建立阅读停顿，不能整屏缺少信息。

## 6. 首页

首屏必须同时有年份、真实地理参考、样本规模及两个清晰入口。海岸线占主视觉；地图上的两个样本地区入口由 `Region` 数据生成，可聚焦时间谱，文字不遮住关键地理区域。后续依次为「同年并行预览」「两件已核实事件」「一件有许可的北宋馆藏」「证据如何工作」。不同段落交替使用深色地图舞台、亮色编辑阅读、数据图和馆藏图像；不排成同款卡片列表。首页数据由现有 `atlas.json` 填充，不在模板硬编码政权名称。

## 7. 历史地图

当前仅展示 Natural Earth 的**现代海岸线**及「历史疆域未录入」标签，不渲染政权边界；两个有数据的地区在图上提供可点击的时间谱入口，位置仅作现代地理定位。未来地图需区分实际控制、法定、宣称；边界精度与不确定性采用虚线、透明度和斜线纹理，并给出来源、许可证和绘制方法。地图是可查询的数据层，不是不能操作的背景照片。无疆域资料时，空状态清楚说明。

## 8. 时间轴

时间谱是主控件，普通 `<input type="range">` 仅保留键盘和辅助操作。中国、欧洲与地中海分轨，政权按实际起止年份投影，研究窗口外的跨度在文字标签中完整显示；拜占庭君士坦丁堡政权的可展示时段不跨过拉丁统治时期。事件以可点击针标示，年份游标跨所有轨道。点击轨道或拖动游标更新政权与君主列表，URL 中的 `year` 可分享。年级粒度表示「该年内至少有一段时间」，不暗示全年持续。

## 9. 政权详情

标题区给出全时段、所属地区和年代证据；正文用杂志式窄栏；侧栏展示已收录君主和相关事件；视觉区用**数据驱动的任期条**，不插入虚构疆域图。君主任期、存在时期及异说逐项链接来源。资料不足处保持留白说明。

## 10. 人物详情

人物页面以姓名和任期为首屏，主栏为短传，旁边是任期／事件的时间对齐图。没有经许可画像时使用「图像档案待核验」文字状态，不用随意生成的肖像冒充史料。亲属和继承关系分别展示；未录入时不画边。

## 11. 事件详情

事件页将年份放大为视觉锚点，参与政权和人物在两侧汇合；下方为叙事、关联项和证据。事件发生地点只显示已核实的地名，未有许可地图时不伪造位置或路线。事件时间的不确定性直接写在标题信息旁。

## 12. 世系图

未来使用双模式：「家族关系」与「任期继承」。节点关联 `Person`，继承线关联 `RulerTerm`；复辟是同一人多任期节点。不同关系用线型和标签区分，不能从血缘自动推算继承。移动端提供可滚动列表替代大图，所有节点可键盘访问。

## 13. 动画与反馈

年份游标和内容更新使用 120–220ms 的轻过渡；事件针、政权条 hover/focus 有明确轮廓和文本反馈。地图层更新不能造成错误的边界插值。尊重 `prefers-reduced-motion`，关闭非必要动效。加载时说明「正在读取样本」，失败时给出可理解的重试提示。

## 14. 响应式

桌面 ≥1200px：地图与导览并列、时间谱完整显示。平板 768–1199px：地图与说明上下排列，时间谱可横向滚动但年份游标仍可见。手机 ≤767px：单列，顶部先呈现年份与入口；时间谱轨道横向滚动，选中年份的摘要固定在轨道附近；无横向页面溢出。交互点击面积至少 44×44px，文字不压在线条上。

## 15. 可访问性与对比度

正文色与背景目标 ≥4.5:1，大字和图形控制目标 ≥3:1；仅用于装饰的细线不承担信息。提供跳转正文、键盘可操作的时间选择、明确的焦点样式、`aria-live` 年份结果、图像替代文本和事件列表替代图形。移动端与缩放 200% 时不丢失入口。正式验收用浏览器检查与对比度工具核对，不只凭视觉估计。

## 16. 图片素材与版权

正式图片须记录原始链接、作者或机构、许可、修改与再发布权限、核对日期；不能仅凭「博物馆网页可看」推断可复制。地理素材为 Natural Earth 公共领域 land 数据的本站 SVG 派生图；首页另收录大都会艺术博物馆 CC0《夏山图》图像，均登记在 `docs/design/assets/README.md`。未验证画像和文物图像均不使用，不从参考站热链、不使用水印图。

## 17. 设计反模式

- 禁止所有页面统一使用米黄色；阅读页用暖白，探索页以海军蓝与墨绿构成独立空间。
- 禁止所有模块使用同一种普通卡片；用地图舞台、轨道、编辑分栏、证据簿各自承担不同信息。
- 禁止反复堆叠「大标题＋短说明＋细线」；每屏必须有明确内容或操作价值。
- 禁止让普通滑动条成为时间轴全部表现；政权跨度和事件针必须可见可点。
- 禁止无意义的圆圈、经纬纹样和伪造的历史坐标；每个视觉标记都要有图例或说明。
- 禁止随机、低质或许可不明的图片填充空位。
- 禁止把地图仅当背景图片；当前海岸线是明确标注的地理参考，未来疆域必须是可查证的图层。
- 禁止所有详情页同构：政权看跨度与统治，人物看任期和事件，事件看参与者与证据。
