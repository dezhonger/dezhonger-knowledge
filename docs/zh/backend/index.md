# 后端工程

后端并不只是连接数据库的 HTTP Handler。它由一组边界构成：哪些输入可信、约束在哪里生效、状态如何改变，以及失败后能够留下什么证据。

## 从服务边界开始

一个可维护的服务应当让以下问题易于回答：

1. 服务拥有哪些状态？
2. 哪些操作可以修改这些状态？
3. 哪些失败可以安全重试？
4. 运维人员如何证明当时发生了什么？

第一篇文章把这些问题应用于一个小型 Go 服务，并避免把简单服务变成复杂框架。
