# 关于本站

Dezhonger 知识库是由 Dezhonger 编写的中英文原创技术笔记。它与[在线工具和个人服务](https://dezhonger.com/?lang=zh)互相补充，但代码仓库和发布周期相互独立。

## 内容原则

- **先看证据，再下结论。** 超时、HTTP 200 或工作流成功都只是一个信号，并不自动构成完整结论。
- **重视系统边界。** 网络、应用、数据库和模型行为应作为相互连接的阶段理解。
- **尽可能精确。** 相比模糊概述，文章优先保留命令、输入、输出、约束和失败条件。
- **能够直接复用。** 文章应在真实实现或故障处理中有用，而不只适合顺序阅读。

## 技术实现

网站使用 Markdown 编写，通过 VitePress 构建，并作为独立的静态 Docker 容器部署。搜索索引在浏览器本地运行。公网 Nginx 将 `/knowledge/` 转发到知识库容器，工具、API、备忘录和数据库仍由独立的 `dezhonger-service` 服务管理。

## 参与修改

每篇文章底部都有 GitHub 编辑入口。欢迎通过 GitHub 提交纠错和范围明确的补充。文章内容应保持原创；依赖外部材料的事实应给出来源。
